# Changelog

## v1.10.0

- Список чатів тепер як у Telegram: папки «всі», «непрочитані», «групи» та «люди», бокове меню з профілем, дзвінками й налаштуваннями, а також окрема вкладка з історією дзвінків.
- Меню повідомлення тепер компактне: невелика сітка кнопок поверх чату, довге натискання працює на будь-якій ділянці повідомлення, а не лише на часі.
- Канал, відкритий із посилання, зберігає свою назву — замість назви групи більше не показується назва населеного пункту.
- Канали та приватні чати, де ви писали, залишаються у списку чатів і не зникають після виходу.
- Видалені повідомлення більше не повертаються з наступним повідомленням у чаті.
- Офлайн-кімната запам'ятовується і з'являється у списку чатів, звідти можна вийти.
- Лендинг і README оновлюються автоматично під час кожного релізу.

## v1.9.0

- Офлайн-кімната в локальній мережі WiFi: телефони кімнати знаходять один одного самі, без налаштування роутера й без інтернету. Повідомлення та файли зашифровані паролем кімнати.
- Файли можна надсилати всередині офлайн-кімнати, отриманий файл відкривається будь-яким застосунком телефона.
- Голосові дзвінки всередині офлайн-кімнати: звук іде по UDP, зашифрований ключем кімнати.
- Кімнати WiFi Direct знову працюють на Android 12 і старших, старий API платформи викликається через reflection.
- Виправлено збій із дубльованими вкладеннями та дубльованим ключем у списку повідомлень.
